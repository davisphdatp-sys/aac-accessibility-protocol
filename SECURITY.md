# Security Policy

This repository contains documentation and testing guidelines only. It does not include executable application code, compiled binaries, or runtime services. The infrastructure is limited to a CI workflow and git hooks.

## Reporting a Vulnerability

If you discover a security concern, please report it responsibly:

### For Sensitive Issues

Use GitHub's private vulnerability reporting. Navigate to the repository Security tab and select "Report a vulnerability." This includes:

- Malicious links or suspicious URLs in the documentation
- Compromised GitHub Actions workflows or automated processes
- Supply chain concerns related to CI dependencies
- Any other issue that should not be discussed publicly

A maintainer will acknowledge your report within 7 days and work with you to resolve it.

### For Non-Sensitive Issues

Open a public issue on GitHub. Clearly describe the problem and include steps to reproduce if applicable.

## Out of Scope

This security policy covers the protocol repository and its documentation only. It does not cover:

- Security or privacy defects in any AAC app or related product. Report those to that product's vendor. This protocol rates no products.
- Requests to evaluate a specific product. The protocol describes how anyone can test an app; the maintainers do not run tests on request.

## Reporter Responsibilities

When reporting a vulnerability:

- Do not include children's names, faces, or personal data.
- Do not include real user information or identifiable details.
- Do not share the report publicly until a fix is available or a reasonable time has passed.

Thank you for helping keep this resource safe and trustworthy.
