# Accessibility of This Repository

We are committed to making this protocol and all supporting documentation accessible to everyone, including people using assistive technologies.

## What We Provide

All documents in this repository are plain Markdown, readable with screen readers. Each file has one logical H1 heading at the top and follows a consistent structure without skipped heading levels. Tables include header rows and avoid merged or layout cells. Every image has meaningful alt text that describes what the image shows and why it matters. Links have descriptive text ("See the testing setup" instead of "click here"). No information is conveyed by color alone. Screenshots attached to issues and pull requests also need alt text.

We do not use em dashes or en dashes, which some screen readers read inconsistently and are hard to distinguish visually. We use plain language and short sentences to improve clarity for all readers.

## CI Checks

Our continuous integration workflow automatically checks Markdown formatting with markdownlint and verifies that links are accessible and working correctly.

## Report an Accessibility Problem

If you encounter an accessibility issue with this repository or its documentation, please open a bug issue and add the label "accessibility." Include:

- What you were trying to do
- What happened instead
- The file or section affected
- Your assistive technology (screen reader, browser, device)

We will investigate and respond as quickly as possible.
